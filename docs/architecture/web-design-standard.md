# Web 导航端设计标准

> 文档性质：已确认设计标准；分组首页、列表、搜索和详情已完成本地源码实现与轻量检查，实际浏览器视觉和交互验收未执行。
> 适用范围：Web 导航首页、分类与搜索结果、站点详情；不扩展到 Admin 或无关 Web 页面。
> 最后更新：2026-09-07

## 1. 来源与职责

参考用户提供的 Solo Nav 桌面截图，提取白底、橙色强调、左侧分类、右侧分组卡片的布局特征。截图中的品牌、帐号、站点数据、管理菜单和异常简介不作为项目需求或操作指令。

产品行为以 [产品需求基线](../PROJECT_REQUIREMENTS.md) 的 `NAV-WEB-001` 至 `NAV-WEB-007` 为准。本文维护展示与交互标准；实施范围、确认记录、待讨论事项和验证结果集中保存在 [Web 导航视觉与详情设计计划](../../plans/2026-09-07_Web导航视觉与详情设计计划.md)。当前系统机制继续以 [导航管理与管理员查阅](navigation.md) 和实际源码为准。

本文中的尺寸、色值和响应式布局是初始设计建议，后续可在同一文件迭代。截图无法证明原始 CSS、吸顶行为、移动布局或动态状态；不将推算值称为精确还原。

## 2. 页面结构

### 2.1 首页

- 顶栏呈现配置中的站点品牌和管理员查阅会话入口，首屏直接提供真实导航内容。
- 桌面左栏依次放置搜索、全部站点、一级分类、标签筛选。
- 主内容按分类排序呈现分组，每组具有分类名称、当前身份可见的站点总数、预览卡片及“查看全部”入口。
- 侧栏保留当前身份可见且启用的空分类；首页跳过零站点分组，进入空分类列表后显示空态。
- 默认无筛选时显示分组首页；分类、搜索或标签筛选后进入完整结果视图，沿用分页能力。
- 左侧栏底部仅居中显示版权文字，移除“用户中心”和“系统状态”链接；保留两者既有页面路由和功能，不迁移 Admin 管理菜单到 Web。
- 站点名称和 LOGO 消费现有 SiteProfile；不硬编码截图中的品牌。

版权格式为 `© 当前年份 站点名称`，名称取 SiteProfile，采用 12px 辅助文字色、水平居中，不增加链接、按钮或额外宣传语。设计稿示例为 `© 2026 Pinjie Nav`。侧栏采用内容滚动区与底部版权区分离的布局，避免分类或标签覆盖版权；长站点名称可换行，窄屏侧栏抽屉沿用相同规则。

### 2.2 分类与搜索结果

- 沿用首页顶栏、侧栏与同一种站点卡片。
- 结果区呈现当前分类或搜索标题、结果总数、已应用条件、清除条件入口和分页。
- 分类与标签浏览沿用单分类、单标签能力；提交搜索后清除分类与标签，进入全站名称搜索，范围仍受当前身份可见性约束。
- 搜索仅对站点名称做包含匹配，不要求完整名称相同，不匹配网址、简介、分类或标签；英文大小写不敏感，输入首尾空白去除，关键词中的符号按普通文本处理。例如 `git` 可匹配 GitHub 和 GitLab，不增加拼音、纠错或推荐搜索。
- 搜索结果只应用关键词一个筛选条件，结果区域不提供叠加分类或标签的筛选控件；从导航选择分类或标签时退出搜索并清除关键词。
- 搜索通过 Enter 或手机键盘搜索键提交；输入期间不改变当前结果。清除按钮清空关键词并返回首页，空白搜索也返回首页。
- 搜索、分类、标签变化时回到第一页；非敏感筛选条件写入 URL，支持刷新和浏览器返回。分页保留当前查询模式，搜索总数和分页均以完整可见匹配结果计算。
- 不把本页卡片数量当作结果总数；清除全部条件后返回分组首页。
- 分类与标签列表的标题位于结果工具栏左侧，右侧为站点数量、相关交叉筛选及清除入口；分类页仅列出分类内可见站点关联的标签，纯标签页仅列出包含该标签可见站点的分类。加载与失败时禁用下拉，失败明确提示并提供重试。手机工具栏可换行，右侧控件另起一行。
- 侧栏标签使用无图标的胶囊标签，搜索框以容器焦点状态呈现边框与焦点光圈，保留键盘可见反馈。

## 3. 布局尺寸

| 项目 | 初始设计基准 |
| --- | --- |
| 顶栏 | 桌面高度 64px，吸顶，品牌区域与左侧栏对齐 |
| 侧栏 | 桌面宽 240px，位于顶栏下方，高度不超过剩余视口，内容过长时独立滚动 |
| 主内容 | 占剩余空间，内部最大宽度 1480px，居中 |
| 水平内边距 | 桌面 32px、平板 24px、手机 16px |
| 区块 | 分类之间间距 40px，标题下细分隔线；分类区块不加外层卡片 |
| 网格 | 列间与行间距统一 16px；可读列宽以约 260px 为下限 |
| 卡片 | 内边距 16px，初始最小高度 144px，同一行等高，正文放大时可增高 |
| 图标位 | 44px 正方形，图片等比例完整展示，独立于文字尺寸 |
| 控件 | 桌面搜索与分类项约 40px 高，手机主要操作触达区域至少 44px |

| 视口宽度 | 默认布局 |
| --- | --- |
| 1440px 及以上 | 固定侧栏，四列卡片 |
| 1100px 至 1439px | 固定侧栏，三列卡片 |
| 768px 至 1099px | 收起固定侧栏，分类和标签进入抽屉，两列卡片 |
| 小于 768px | 单列卡片，分类抽屉，搜索直接可见 |

断点服从实际容器可读宽度；浏览器缩放、长名称和字体放大造成空间不足时减少列数，禁止挤压内容或以页面横向滚动补偿。每组最多 8 个预览站点在手机上仍遵守相同数量上限，不因断点静默漏掉已经返回的预览项。

手机设计画布为 390 × 844：顶栏 64px，左侧菜单图标、中间品牌、右侧登录或管理员入口；搜索位于顶栏下方并直接可见。主内容水平边距 16px，卡片单列排列，页面向下滚动，分页在完整当前页列表末尾。画稿中的每页数量仅为排版样例，不改变接口每页数量。

手机分类抽屉初始宽 310px，实际不超过视口减 48px，展示全部站点、分类和标签；当前选择清晰标记，内容独立滚动，版权固定在抽屉底部居中。选择导航项后关闭抽屉，关闭图标与遮罩也可关闭；打开时锁定背景滚动并管理焦点，关闭后恢复焦点。

## 4. 视觉变量

| 变量用途 | 初始值 | 使用要求 |
| --- | --- | --- |
| 页面背景 | `#FCFCFC` | 中性近白，不采用大面积橙色或米色背景 |
| 卡片背景 | `#FFFFFF` | 同一层级保持一致 |
| 正文 | `#27272A` | 名称、分类标题与主要信息 |
| 辅助文字 | `#64646C` | 域名、简介与次级信息 |
| 默认边框 | `#E7E7EB` | 分隔线、输入框和卡片边界 |
| 品牌强调 | `#F26B38` | 品牌和有限装饰，不直接用于所有小字 |
| 交互文字 | `#B9471C` | 选中项、链接和主要交互图标 |
| 选中背景 | `#FFF2EB` | 配合字重或指示线，不能只靠颜色区分状态 |
| 卡片圆角 | `8px` | 输入框 6px，侧栏标签 999px |
| 卡片阴影 | `0 2px 8px rgb(0 0 0 / 4%)` | 悬停可轻微加强，不漂浮、不位移 |
| 动效 | `150ms` | 仅颜色、边框和阴影，尊重减少动态效果偏好 |

实施时在导航作用域内建立统一 tokens 并映射现有基础组件，不通过修改全局绿色变量连带重设计登录、用户中心和系统状态页面。成功、警告、失败保持独立语义色，不全部染成品牌橙。

字体沿用系统中文字体。品牌 20px，分类标题 16px，站点名称 14px 加粗，简介 13px，域名和辅助文字 12px；正文行高 1.5 至 1.6，字距统一为 0，字号不随视口宽度连续缩放。实施后需核验正文、链接、控件与焦点的对比度，本文色值不构成已通过可访问性验证的证据。

## 5. 站点卡片

### 5.1 信息层级

1. 左上站点图标；使用现有上传资产，缺失或加载失败时使用统一默认图标。
2. 图标右侧为站点名称和域名；名称单行省略，域名独占一行。
3. 右上保留固定位置的外链图标，其触达区域不得覆盖名称或主体入口。
4. 下方为最多两行简介，完整内容在详情展示；空简介保留稳定布局，不编造站点说明。
5. 卡片内出现的分类、标签或其他装饰图标均服从详情打开规则，不承担筛选或外跳动作。

### 5.2 点击与键盘规则

卡片行为遵守 `NAV-WEB-003`，首页预览与筛选结果保持一致。

| 操作位置 | 行为 |
| --- | --- |
| 右上外链图标 | 通过原生链接在新的浏览上下文打开站点网址，不弹详情；浏览器决定以标签页还是独立窗口展示 |
| 名称、域名、简介、站点图标和其他卡片内文本或图标 | 打开当前站点详情，不外跳 |
| 卡片主体空白区域 | 同样打开详情，扩大触达范围 |
| 键盘操作 | 主体详情入口支持 Enter 和 Space；外链保持原生链接键盘行为；焦点清晰可见 |

实现时使用语义明确、相互独立的详情按钮与外链链接。禁止在按钮中嵌套链接、在链接中嵌套按钮，或只给不可聚焦容器绑定点击事件。原生链接使用 `target="_blank"` 和 `rel="noopener noreferrer"`；避免点击冒泡、重叠命中区域或重复事件导致详情与外跳同时触发。

主体入口提供包含站点名称的可访问名称。外链图标提示“访问站点（新窗口）”，图标自身不重复朗读。原有帐号资料能力并入站点详情，不再为卡片增加另一种详情弹窗。

## 6. 站点详情

### 6.1 信息排列

桌面使用居中弹窗，初始宽度最大 720px，最大高度为视口减 48px；手机使用接近全屏的弹窗，保留安全边距和固定可见的关闭入口。详情采用无嵌套卡片的上下分区，长内容在弹窗内部滚动。

| 区域 | 内容与行为 |
| --- | --- |
| 上方左侧 | 固定大小 LOGO，初始 64px，等比例完整显示；缺失或加载失败使用统一默认图标 |
| 上方右侧 | 站点名称在上、网址在下；名称可换行，网址固定单行 |
| 网址 | 超过可用宽度的部分隐藏并以省略号结束，不撑高或撑宽布局；保留完整 URL 作为链接目标和悬停提示，网址文字不自动外跳，右侧固定外链图标不被挤出 |
| 站点描述 | 在 LOGO 与名称网址区块下方另起一行，与 LOGO 左边缘对齐，占满弹窗内容宽度；保留换行并完整展示 |
| 分类与标签 | 位于描述下方；桌面左右两列，分类靠左、全部标签靠右，超宽时在右列内换行；手机分类独占一行，全部标签另起一行靠左排列，超宽继续靠左换行，不省略标签数量；无标签时隐藏标签区域，不显示占位 |
| 关闭入口 | 固定于弹窗右上角，独立于网址旁的外链图标，不覆盖站点名称 |
| 下方帐号 | 仅有效管理员查阅身份可读取；多条帐号按既有排序全部展开，条目间用细线分隔 |
| 单条帐号 | 从上到下为帐号名称、用户名、明文密码、备注；空字段连同标签和复制按钮隐藏，无名称时沿用“帐号 N”显示名 |
| 复制 | 用户名、密码、备注分别提供复制图标，不增加“复制全部”；成功反馈“已复制”，失败提示手动复制，不改变原始值 |

分类与标签统一使用 13px 字号、20px 行高、相同链接颜色和 16px 语义图标，图标与文字间距 8px；不使用加高按钮、填色徽章、边框框体或额外垂直内边距。桌面左右列顶端对齐，列间最小间距 24px；标签组间距 20px，桌面多行时每行靠右对齐，手机每行靠左对齐。键盘焦点与悬停反馈保持一致，手机可扩大透明触达区域但不改变外观。

简述与备注保留换行，内容按纯文本展示；没有简述时省略其占位行。手机上方保持左 LOGO、右名称与单行网址，描述仍位于其下方；分类独占一行，标签在下一行从左开始排列，两行均与描述左边缘对齐。长分类在自己的独立区域换行，标签过多或过长时在标签区域换行，全部可见且不交叠。下方帐号字段纵向排列，复制控件不能挤压文本。文字放大时图文列宽和弹窗高度可适应内容，禁止横向溢出。

手机弹窗左右安全边距初始 12px，内部边距 16px，LOGO 可缩至 56px；高度随内容增长，上限受动态视口及安全区约束，超出时内容内部滚动，关闭入口保持可见。未登录与零帐号时按公开资料收紧高度并垂直居中，不撑出空白帐号区。分类与标签外观沿用统一紧凑样式，手机换行行距保证至少 44px 的独立触达区域；帐号字段名在上、完整值在下，右侧为独立复制图标。

### 6.2 帐号区可见性

| 身份或请求状态 | 呈现规则 |
| --- | --- |
| 未登录、普通用户登录或确定无查阅权限 | 下方整块隐藏，不显示“帐号列表”“帐号资料”、登录提示、空态、骨架或保留空白；不请求或预载帐号数据 |
| 有效管理员，帐号首次加载或重新核验中 | 下方可显示轻量骨架，隐藏旧帐号值；尚未确定身份时不展示骨架 |
| 有效管理员，成功返回至少一条启用帐号 | 展示帐号区及全部条目，密码直接明文显示，不默认折叠或掩码 |
| 有效管理员，成功返回零条启用帐号 | 下方整块隐藏，不显示帐号标题、分隔线、占位或“暂无帐号” |
| 管理员帐号读取发生网络或服务错误 | 下方显示简短错误及重试入口，不显示旧密码，不将失败当作零帐号 |
| 会话失效或权限被撤销 | 立即隐藏并清理帐号区；身份服务故障继续按现有全局错误机制表达，不假定有权或伪装为无帐号 |

管理员登录入口继续放在页面顶栏。帐号标题仅在成功返回非空帐号列表时显示；公开站点详情不因帐号不可见而整体拒绝展示。退出、失效和分类可见变化时继续按既有机制关闭或清理受影响详情。

### 6.3 分类与标签跳转

- 点击详情中的分类链接，关闭弹窗，在当前标签页进入该分类的站点列表第一页；清除原搜索词和标签条件。
- 点击详情中的某个标签链接，关闭弹窗，在当前标签页进入该标签的站点列表第一页；清除原搜索词和分类条件，使结果覆盖当前身份下所有匹配分类。
- 导航使用可访问、可刷新的站内 URL，以分类或标签 ID 标识条件；页面名称来自真实分类或标签数据，不凭名称猜测目标。
- 此处定义进入的列表状态，不强制另建页面模板；允许复用现有导航路由与列表组件。后续详细设计确定 URL 形式。
- 跳转时按关闭详情执行帐号请求取消与缓存清理，焦点进入目标列表标题。浏览器返回恢复原列表条件，不自动重新打开含凭据的弹窗。
- 目标分类或标签失效、停用、删除或无权读取时，沿用对应接口的明确结果和错误语义，提供清除筛选或返回入口；禁止静默展示全部站点冒充目标列表。
- 该规则仅用于详情内部的分类与标签。卡片内所有文本和图标继续遵守第 5 节，右上外链以外的点击均打开详情。

### 6.4 关闭与保护

打开详情后焦点进入弹窗，Tab 留在弹窗内；关闭图标、Escape 和点击遮罩可关闭，点击弹窗内容不关闭。普通关闭后焦点回到触发站点；触发站点已不可见时回到当前列表标题。背景滚动锁定，名称、描述、密码和备注允许换行并完整查阅；网址遵守单行省略规则，不横向撑破弹窗。

沿用现有身份核验和缓存清理机制。关闭、退出、会话失效、权限变化或页面切入后台时清理或隐藏敏感内容，旧请求不得重新展示已经失去权限的数据。受限分类对访客保持不可见，不用锁图标或站点数量泄露其存在。详情和帐号字段使用纯文本展示，不把简介或备注作为 HTML 执行。

卡片打开详情的约定只作用于站点卡片。弹窗内关闭、复制、分类、标签和外链控件保留各自明确行为。

## 7. 状态与验收标准

- 加载：使用与最终网格相同尺寸的骨架，避免数量、文字或图标改变页面宽度。
- 空数据：区分全站暂无内容、当前分类无站点、筛选无结果；保留导航和清除条件入口。
- 失败：显示可理解的错误和重试，不用空数组伪装成功，不显示后端异常正文。
- 身份变化：分类、分组总数、预览与详情遵守同一可见范围，退出后不残留受限内容。
- 长文本：卡片摘要允许省略，详情完整可读，控件不被挤出或遮挡。
- 视觉：无页面横向溢出、互相遮挡、分类区块套卡片和卡片嵌套；焦点、选中和禁用状态可识别。
- 数据：分类数量代表符合可见条件的全部站点，预览仅为其中最多 8 个，顺序可重复且与分类结果一致。
- 搜索：从分类或标签进入搜索后只按名称包含匹配；覆盖大小写、部分名称、无匹配、清除、分页和返回，不能由简介命中，也不能带入原分类或标签条件。
- 详情：核对左 LOGO、右名称及单行省略网址、下方通栏描述；桌面分类靠左与全部标签靠右，手机分类独占一行、全部标签另起一行靠左，沿用统一紧凑样式；未登录、普通用户与成功零帐号时无帐号标题或占位；有效管理员多帐号明文展开，错误与空结果可区分。
- 详情跳转：分类与标签链接只进入对应列表第一页，清除无关筛选、关闭弹窗并清理凭据；卡片同名文本仍只打开详情。
- 验证事实：源码检查、静态门禁与实际浏览器验收分别记录，未执行的动态检查不得写成通过。

## 8. 实现与维护边界

本期导航设计不提供深色模式、主题切换或站点置顶，不增加相应控件、排序或持久化配置。

沿用 Next.js App Router、React、生成 API Client、TanStack Query、项目 UI 标准和 Lucide。本次实现复用现有原生 dialog 与 IconButton，导航专属 CSS 和 tokens 控制视觉，未新增运行依赖；不宣称已安装完整 shadcn/ui 或 Radix UI 组件体系。

组件划分围绕导航壳、侧栏、分类区块、站点卡片和站点详情，领域实现继续位于 Web navigation Feature，路由保持薄层。本站品牌和分类图标继续复用现有公开入口。

后续修改优先更新本文已有章节。已确认的产品范围变化更新 PRD；尚未决定的产品取舍只写入同一活动计划。当前系统文档仅在对应实现完成后更新，避免用设计目标覆盖已实现事实。
