# ADR 0016: 管理员身份与导航只读会话决策

- 状态：已实施，真实环境验收未执行
- 日期：2026-09-06
- 决策者：大仙
- 关联计划：[导航管理与管理员只读查阅计划](../../plans/2026-09-06_导航管理与管理员只读查阅计划.md)

## 背景

个人导航由 Admin 维护，Web 向访客公开导航，向具备权限的管理员展示外网凭据。现有 Web 用户身份不参与该业务，现有 Admin Logout 行为必须保持。

## 决策

1. 保留现有 Admin 和普通用户认证，新增独立导航只读会话，禁止把 Admin Token 透传到 Web。
2. 统一登录入口通过管理员现有认证完成身份核验，使用受控的一次性授权流程建立查阅会话；会话令牌仅通过 HttpOnly、SameSite=Lax、生产 Secure 的 Host-only Cookie 传递。
3. 登录请求必须具有随机 state、S256 浏览器请求绑定和短时有效期。授权凭证单次消费，回调为精确配置的 Web 地址，不允许任意 return URL。借鉴 RFC 7636 与 RFC 9700，不声明提供完整第三方 OAuth 服务。
4. 回调只允许短期、单次、绑定浏览器请求的一次性授权码，使用 URL fragment 传递并立即清除，再以同源 POST 消费；fragment 不进入服务器访问日志。不在 URL 放置 Access、Refresh 或查阅会话令牌。回调使用 no-store、no-referrer，日志禁止记录正文。这是针对授权回调的窄范围协议说明，不放开普通 Token 的 URL 禁令。
5. 查阅会话保存管理员标识、凭据版本、期限和撤销状态；读取时检查当前管理员状态和凭据查看权限。签发完成后不依赖原 Admin Session 存活，保证 Admin 普通退出不撤销 Web。
6. Web Logout 只撤销当前查阅会话，并记录自动登录抑制；显式登录后解除抑制。Admin Logout 不新增任何导航副作用。不提供全端退出功能。
7. Web 凭据接口与公开接口使用不同输出 Schema。Web 会话只能查阅，所有业务写接口仍要求管理会话、准确权限、CSRF 和审计。
8. 按用户明确选择，外网用户名、密码和备注明文存储，授权后展示；管理员登录密码继续 Argon2id。禁止凭据进入公开响应、持久化浏览器缓存、日志、错误和审计正文。

## 代价与备选方案

- 共享 Admin Cookie 会扩大 Web 权限范围，并改变现有 Profile 边界，因此不采用。
- 每端重复输入管理员密码实现成本较低，但不满足已有后台登录免重复输入的要求。
- 新增独立查阅会话和授权状态提高实现成本，换取明确的只读能力与独立退出语义。
- 明文数据库与备份泄露将暴露凭据，访问控制不能消除这一风险。

## 验证与回滚

- 必须覆盖回调绑定、state/S256、重放、过期、跨身份越权、两端独立退出、主动退出后不自动重登、管理员状态及权限失效。
- 只运行当前授权的轻量门禁；真实数据库与浏览器认证验收另行点名执行，未执行明确记录。
- 前期通过增量新增接口和数据表保留原有功能。回退应用时保留已写入导航数据，不以删表作为生产恢复默认方案。
