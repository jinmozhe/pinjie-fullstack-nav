# 分类图标配置计划

## 当前状态和结果

- 状态：已结束
- 结果：已完成；分类图标源码、迁移文件、生成契约和本地轻量验证完成，实际迁移与重型验收未执行。

## 关联需求

- `NAV-CAT-001`：一级分类增加可选内置图标。
- `NAV-ADMIN-001`：Admin 维护分类图标，沿用权限和审计。
- `NAV-WEB-001`：Web 分类导航展示所选图标。

## 背景

用户确认采用内置图标选择方案，分类表达通用含义，站点 LOGO 继续采用原有上传能力。

## 目标

- 分类可搜索、预览、选择和清除内置图标，保存后列表与 Web 分类导航同步表达图标语义。
- 后端持久化并校验稳定标识，默认无选择，已有分类显示默认图标。
- 同步数据库迁移、唯一 OpenAPI、生成客户端、需求及操作文档。

## 非目标

- 不增加分类图片上传、图标颜色配置或标签图标。
- 不改变站点图标、分类权限、批量操作、删除确认及跨端身份流程。
- 不执行数据库迁移、production build、pytest、Vitest、浏览器自动化、Git 提交、发布或部署。

## 现状分析

`NavCategory` 只有名称、说明、排序、启停和登录可见字段。Admin 的 `TaxonomyManager` 同时服务分类与标签，Web 分类按钮只展示名称。分类接口复用带类别路径的联合 Schema，必须阻止分类专用字段流入标签。

## 方案设计

- 新增可空 `icon_key` 字符串列和允许值检查约束；请求 Schema 使用有限字符串集合，响应通过生成契约供前端消费。
- 首批提供开发、阅读、工具、应用、网站、云服务、数据库、接口、设计、图片、视频、音乐、人工智能、数据分析、教育、资讯、社区、购物、游戏、安全共 20 类语义。
- Admin 使用现有 Ant Design Select 与静态导入的 `@ant-design/icons`，搜索支持中文标签和英文标识，选项及当前值均预览图标，支持清除为 null。
- Web 使用现有 Lucide 图标映射，同一标识表达同一语义；null 显示默认文件夹。两端映射用生成字段类型约束完整性，不增加共享 DTO、跨应用引用或依赖。
- 数据库新增 `20260907_02`，承接 `20260907_01`；已有行保持 null，不修改既有迁移。禁止通过 downgrade 丢弃已保存配置，回滚保留字段并前向修复。
- 分类列表继续由 ProTable 处理空态、工具栏、刷新、批量操作与权限；增加固定宽度图标列，表单保存失败保留草稿。
