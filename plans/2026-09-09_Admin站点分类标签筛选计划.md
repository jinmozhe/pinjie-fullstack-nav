## 现状与方案

Backend admin_sites 已接收 category_id 和 tag_id，Repository 在分页与总数查询前应用条件，关键词可叠加；唯一 OpenAPI 已声明参数。Admin 封装与 SitesManager 尚未传递分类标签条件。

复用现有 Ant Design Select 和后台 taxonomy 查询，在列表上方提供分类、标签筛选和清空筛选按钮；保留列表标题、刷新、关键词搜索及所有操作。分类与标签可搜索、单独清空，列表显示停用选项标记。选项加载失败明确反馈并允许重试。

筛选值进入 Query key 和 API 参数，变化时重置页码并清空选择；搜索保留分类、标签条件，刷新和翻页保留所有条件。回收站继续传 deleted=true。无写权限的管理员仍可筛选其有权读取的站点。
