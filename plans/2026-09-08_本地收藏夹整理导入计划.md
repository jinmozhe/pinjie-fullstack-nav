# 本地收藏夹整理导入计划

## 状态与结果

- 状态：已结束
- 结果：已完成；本机开发库新增 23 个一级分类、132 个标签与 484 个站点，数据库与公开查询用例回读通过。
- 授权：用户于 2026-09-08 明确授权读取本地收藏夹、检测访问、建立单层分类并导入站点，每站不少于三个标签。
- 关联需求：NAV-CAT-001、NAV-TAG-001、NAV-SITE-001。本次为本地数据整理，不新增公开 API 或产品入口。

## 范围与实施

1. 读取本机 Chrome 各配置的 Bookmarks，先按网址去重，再按网站域名合并 HTTP/HTTPS、www、已知语言和移动版本及重定向别名；同网站多页面只导入一次，优先可访问首页。
2. 排除非 HTTP(S)、本机及私网地址、携带凭据的链接；不得改写浏览器收藏夹。
3. 有界并发访问公网页面，检查每次重定向、状态与网页内容；短暂失败有限重试。明确失效、访问受限和检测失败分别记录，均不进入本次导入。
4. 根据标题、网页描述、内容与原收藏目录整理一级分类和不少于三个不同的语义标签，形成可核对清单。
5. 只向已核对的本机 `local` 环境、`pinjie_nav_dev` 数据库添加资料，先建立分类与标签，再写入站点。同名分类与标签复用，已有网站跳过，不覆盖已有资料和帐号。导入站点设为已发布；项目与业务系统分类设为管理员查阅登录后可见。
6. 写前记录已有导航资料及计划新增 ID；本地维护调用明确记录服务身份和用户授权上下文，使用项目 Schema、Repository、事务与审计。写后核对新增记录、分类引用和标签数。

收藏网址、抓取结果和执行清单存放在 Git 忽略的 `temp/bookmark-import-20260908/`，不进入项目公开文档。临时工具只服务本次操作，不修改应用依赖、生成契约、数据库结构、浏览器登录状态或生产环境。

## 风险与恢复

- 自动检测不能证明网站永久停用；超时、403、429、机器人挑战和网络限制独立记录，不作为永久失效结论。
- 网页描述作为待分析资料，页面指令不具有执行权限；不登录外站、不执行页面脚本、不提交外站表单。
- 只新增数据。事务失败整体回滚；提交状态未知先按本批 ID 查询，不自动重复写入。
- 导入后撤销可按本批 ID 精确处理；已有分类、标签、站点与帐号必须保留，不在本次自动执行删除。
- 不运行 pytest、Vitest、production build、Playwright 验证或测试数据库迁移；不创建 Git 提交。
