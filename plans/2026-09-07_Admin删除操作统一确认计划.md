# Admin 删除操作统一确认计划

## 状态与范围

- 状态：已结束
- 结果：已完成；本地源码、相关规则与轻量验证完成，动态交互和视觉验证未执行。
- 关联需求：`NAV-ADMIN-001`、`NAV-SITE-001`、`BASE-ADMIN-004`、`BASE-ADMIN-007`。
- 目标：管理端所有立即提交的软删除、硬删除及已保存 LOGO 移除，在单条和批量入口均先确认；站点列顺序调整为 LOGO、站点、分类、网址、标签、排序、状态、操作。
- 非目标：改变后端删除语义、权限、契约、数据库、发布或部署；同步母版；为只修改表单草稿的图标移除增加弹窗。
- 用户确认：2026-09-07 用户明确要求所有“移入回收站”“删除”等操作二次确认，并选择上述列顺序，授权本地实现和默认轻量验证。此授权覆盖本计划，无需重复确认。
- 待确认问题：无。

## 方案与影响

复用 `StandardConfirmModal`，固定“确定”“取消”，允许嵌入用户删除原因。点击删除时保存目标 ID 或 LOGO revision，确认才发请求；取消不写入，失败保留目标和草稿，执行期间禁止重复提交与关闭。既有硬删除入口继续复用该组件。

| 范围 | 是否涉及 | 工作内容 | 前置依赖 | 验证 |
| --- | --- | --- | --- | --- |
| Backend | 不涉及 | 删除语义与授权不变 | 无 | 源码核对既有 API |
| Admin | 涉及 | 通用确认组件、站点、用户、设置页及相关测试源码 | 现有批量 API | typecheck、lint；测试运行未授权 |
| Web | 不涉及 | 无页面修改 | 无 | 范围核对 |
| API Client | 不涉及 | 无契约变化 | 无 | 不重新生成 |
| Database | 不涉及 | 不执行数据操作或迁移 | 无 | 范围核对 |
| Deployment | 不涉及 | 无发布、部署或服务操作 | 无 | 范围核对 |
| Documentation | 涉及 | Admin 规则、需求、架构、ADR 0017、索引与变更记录 | 用户确认 | Markdown、text、documents、workspace、boundaries |

## 风险与回滚

- 公共组件影响全部删除弹窗，重点核对重复点击、取消与失败后的重试。LOGO 使用打开弹窗时的 revision，避免误删后来更新的图片。
- 不执行真实删除；回滚仅逐块撤销本任务补丁并同步当前规则，不覆盖已有修改，不删除计划和历史 ADR。
- 确认弹窗只防误操作，服务端权限、CSRF 和审计继续独立生效。
